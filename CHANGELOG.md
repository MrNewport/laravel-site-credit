# Changelog

## 1.0.0

- Shared BWD attribution, preserving the wording and destination used by DRD Trailers.
- Auto-discovered Blade component and shared configuration payload for Vue/Inertia.
- Optional Vue source component, framework-independent stylesheet and publishable static CSS.
- Escaped text, safe web links, keyboard focus treatment, and inherited or explicit themes.
- Laravel 12/13 compatibility; no database, tracking, network calls, or cloud services.
